끝말 사전은 표준국어대사전에 등재된 단어를 찾아보는 작은 데스크톱 프로그램입니다. 게임 옆에 띄워 두고 시작 글자로 후보와 뜻을 확인하세요.

작은 창에 필요한 기능만

시작 글자로 검색

공식 사전 API로 단어와 뜻을 조회합니다. 기본 검색은 두 글자 이상의 명사입니다.

항상 위에 고정

기본 360×440 크기의 창을 게임 옆에 배치하고 필요에 따라 크기를 조절합니다.

후보와 턴 넘기기

원하지 않는 후보를 넘기거나 검색을 비워 다음 턴을 준비합니다.

복사와 사용 기록

단어를 복사하고 이번 게임에서 사용한 후보를 제외합니다. 다음 검색은 마지막 글자로 시작합니다.

표준국어대사전 API 이용 목적

이 프로그램은 국립국어원 표준국어대사전 검색 Open API를 이용해 사용자가 입력한 시작 글자에 해당하는 표제어, 뜻풀이 및 사전 원문 링크를 조회·표시하기 위해 개발되었습니다. 임의의 단어 목록이나 다른 사전의 단어를 검색 결과에 섞지 않습니다.

  • 요청 대상: https://stdict.korean.go.kr/api/search.do
  • 이용 형태: Windows 데스크톱 앱에서 사용자가 검색할 때 HTTPS 요청
  • 표시 내용: 검색 조건에 맞는 단어, 뜻풀이, 공식 사전 원문 링크
  • 이 페이지는 프로그램 소개 페이지이며, 웹에서 사전 검색을 제공하지 않습니다.

공식 Open API 이용·인증키 발급 안내 ↗

개별 사용자가 발급받은 API 인증키를 앱 설정에 입력해야 검색할 수 있습니다. 인증키는 실행 중 메모리에만 보관하며 별도 파일이나 이 소개 페이지에 저장하지 않습니다. 검색어와 인증키는 검색 요청 시 공식 사전 API로 전송됩니다.

사용 방법

  1. 프로젝트의 README에 따라 Windows에서 앱을 실행합니다.
  2. 설정에 표준국어대사전 API 인증키를 입력합니다.
  3. 시작 글자를 입력하고 검색을 누릅니다.
  4. 후보를 확인해 복사한 뒤 게임에 직접 붙여넣습니다.

게임의 입력이나 패스 버튼을 자동으로 조작하지 않습니다. 두음법칙과 게임별 금지어는 직접 확인해야 하며, 사전 등재어도 게임 규칙에 따라 사용할 수 없을 수 있습니다.

개발 및 문의

TypeScript와 Electron으로 개발한 Windows용 프로젝트입니다. 현재 개발 중이며, 설치와 빌드 방법은 저장소에서 확인할 수 있습니다.
